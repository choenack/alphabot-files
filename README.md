# coin ai — 업비트 코인 자동매매 (내 PC 실행용)

업비트 원화마켓 **현물**을 공격적으로 단기 추세 매매하는 봇입니다. 내 Windows PC(`C:\coin ai`)에서 혼자 돌리는 용도예요.

- **1차 필터(코드)**: 거래대금 상위 30개 코인에서 돌파·눌림목 셋업을 찾아요. 대부분은 여기서 걸러져서 LLM 비용이 안 들어요.
- **판단(LLM)**: 셋업이 잡힌 코인만 DeepSeek V4.1 Flash가 진입할지(ENTER/SKIP)와 확신 등급(high/normal)을 정해요.
- **가격·손절·매도(코드)**: ATR(평균 변동폭)로 손절선을 정하고, 수익이 나면 본전 스탑을 거쳐 트레일링 스탑으로 따라가요. 익절 상한은 없어요.
- **자가진화**: 한 달에 한 번 Claude Fable 5.1이 판단 기록을 분석해서 새 프롬프트를 만들어요. 2주 동안 비교해 보고 더 나을 때만 교체해요.

> ⚠️ 실제 돈으로 주문하는 프로그램이에요. 손실이 날 수 있고, **PC가 꺼져 있는 동안에는 손절도 멈춰요.**

## 0. 가장 쉬운 방법: `coin-ai.exe` 하나로 실행

파이썬 설치 없이 exe 파일 하나로 돌아가요. 실행하면 브라우저에 **대시보드**가 자동으로 열려요.

1. GitHub 저장소 `choenack/alphabot-files` → **Releases → "coin ai (최신 빌드)"**에서 `coin-ai.exe`를 내려받아요.
   - Releases에 없으면 **Actions → build-exe → 가장 최근 실행 → Artifacts의 `coin-ai-windows`**에서 받을 수 있어요(zip 안에 exe가 있어요).
2. `C:\coin ai` 폴더를 만들고 `coin-ai.exe`를 넣어요.
3. 더블클릭해서 실행해요. 서명되지 않은 exe라 처음에 "Windows의 PC 보호" 창이 뜨면 **추가 정보 → 실행**을 누르세요.
4. 브라우저에 대시보드(`http://127.0.0.1:8765`)가 열려요. **설정 탭**에서 업비트 키, DeepSeek 키를 넣고 **저장하고 적용**을 누르면 바로 매매 엔진이 켜져요.
   - 키는 같은 폴더의 `.env` 파일에만 저장되고 화면에 다시 보이지 않아요. 상태 파일(`coinai.db`)과 로그(`coinai.log`)도 이 폴더에 생겨요.
5. 끌 때는 대시보드의 **종료** 버튼을 누르세요. 걸어둔 매수 주문을 정리하고 꺼져요. 검은 창을 그냥 닫아도 꺼지지만 정리는 안 돼요.

**업데이트**: 새 `coin-ai.exe`를 받아서 덮어쓰면 돼요. `.env`와 `coinai.db`는 그대로 두세요.
**켜면 자동 실행**: `Win + R` → `shell:startup` → 열린 폴더에 `coin-ai.exe` 바로가기를 넣어요.
**두 번 실행 방지**: 이미 켜져 있으면 새로 켜지지 않고 대시보드만 열려요.

### 대시보드에서 할 수 있는 것

| 탭 | 내용 |
|---|---|
| 개요 | 봇 자산, 오늘 손익, 실현 손익, 승률, 총이익÷총손실, 원화 잔고, LLM 비용 · **보유·대기 코인**(수익률, 손절선, 트레일링 여부, **청산/취소 버튼**) · **자산 vs BTC 보유 비교 차트**(1일/7일/30일/전체) · BTC 상태 · 최근 스캔 셋업과 LLM 판단 · 감시 코인 |
| 매매 기록 | 청산된 매매(손익, R, 사유, 보유 시간), 최대 낙폭, 운용금 |
| 판단 기록 | LLM 판단 기록(24시간 뒤 결과 포함) · 자가진화 상태와 **지금 실행** 버튼 |
| 설정 | API 키 입력 · 운용 금액과 매매 설정 변경(저장하면 바로 적용) · **점검 실행**(키·IP·잔고·LLM 확인, 주문 안 함) |
| 로그 | 최근 실행 로그 |

위쪽 버튼: **신규 진입 일시정지/재개**(보유분 손절 감시는 계속) · **엔진 켜기/끄기** · **테마**(자동/밝게/어둡게) · **종료**.

**휴대폰으로 보기(같은 와이파이)**: `.env`에 `DASHBOARD_HOST=0.0.0.0`과 `DASHBOARD_PASSWORD=원하는비밀번호`를 넣고 다시 켜요. 휴대폰 브라우저에서 `http://<이 PC의 내부 IP>:8765`로 접속하면 비밀번호를 물어봐요. Windows 방화벽 창이 뜨면 "개인 네트워크"만 허용하세요. 비밀번호가 없으면 외부 접속은 열리지 않아요.

**exe를 직접 만들고 싶으면**: 아래 1번(파이썬 설치) 후 `build_exe.bat`을 실행하면 같은 폴더에 `coin-ai.exe`가 생겨요.

## 1. 파이썬으로 설치 (`C:\coin ai`)

### 방법 A: git으로 받기 (추천, 업데이트가 쉬움)
[Git for Windows](https://git-scm.com/download/win)를 설치한 뒤 명령 프롬프트(cmd)에서 실행하세요.

```bash
git clone -b claude/quirky-shannon-7ftto9 https://github.com/choenack/alphabot-files.git "C:\coin ai"
```

나중에 코드가 바뀌면 `update.bat`을 더블클릭하면 돼요.

### 방법 B: ZIP으로 받기
1. GitHub에서 `choenack/alphabot-files` 저장소를 열고, 브랜치를 `claude/quirky-shannon-7ftto9`로 바꿔요.
2. **Code → Download ZIP**으로 내려받아요.
3. 압축을 풀고, 안에 있는 파일 전부를 `C:\coin ai` 폴더에 복사해요.

### 그다음 공통
1. [Python 3.11 이상](https://www.python.org/downloads/)을 설치해요. 설치할 때 **"Add python.exe to PATH"를 꼭 체크**하세요.
2. `C:\coin ai\install.bat`을 더블클릭해요. 필요한 패키지를 설치하고 `.env` 파일을 메모장으로 열어 줘요.
3. `.env`에 API 키를 넣고 저장해요. (아래 2번 참고)
4. `check.bat`을 더블클릭해요. 키, IP, 잔고, 감시 대상, LLM 연결을 점검하고, **주문은 하지 않아요.**
5. 문제가 없으면 `run.bat`을 더블클릭해서 실전 매매를 시작해요. exe와 똑같이 브라우저에 대시보드가 열려요.

## 2. API 키 준비

| 키 | 어디서 | 주의 |
|---|---|---|
| 업비트 | 업비트 → 마이페이지 → Open API 관리 | 권한은 **자산조회 + 주문조회 + 주문하기**만. **출금하기는 절대 체크하지 마세요.** 허용 IP에 이 PC의 인터넷 IP를 등록해요(네이버에서 "내 IP" 검색). |
| DeepSeek | platform.deepseek.com | 소액 충전 필요. 매매 판단용이고 월 수천 원 수준이에요. |
| Claude (선택) | console.anthropic.com | DeepSeek 장애 시 예비 판단과 월 1회 자가진화에 써요. 없으면 이 두 기능만 꺼져요. |
| 텔레그램 (선택) | 텔레그램에서 @BotFather로 봇 생성 → 토큰 / @userinfobot에게 말 걸면 chat id | 진입, 청산, 손절, 에러, 하루 요약이 휴대폰으로 와요. |

**IP가 바뀌면** 업비트가 주문을 거부해요. 이때 텔레그램으로 알림이 오니, 업비트 Open API 관리에서 허용 IP를 새 주소로 바꿔 주세요.

## 3. PC 설정 (중요)
- **절전**: 봇이 켜져 있는 동안은 봇이 자동으로 절전을 막아요(화면은 꺼져도 괜찮아요). 노트북이라면 **덮개를 닫아도 절전하지 않게** 전원 옵션을 바꿔 두세요.
- **윈도우 업데이트 자동 재시작**: 설정 → Windows 업데이트 → 고급 옵션에서 "사용 시간"을 하루 종일로 잡거나, 업데이트를 일시 중지해 두세요.
- **켜면 자동 실행**: `Win + R` → `shell:startup` 입력 → 열린 폴더에 `run.bat` 바로가기를 넣으면, 로그인할 때 자동으로 시작돼요.
- **끌 때**: 봇 창에서 `Ctrl + C` → `Y`를 누르세요. 창을 그냥 닫으면 걸어둔 매수 주문이 취소되지 않아요. (다시 켜면 정리되긴 해요)
- 봇이 오류로 죽으면 `run.bat`이 30초 뒤에 자동으로 다시 켜요.

## 4. 매매 규칙 (기본값 = 공격적 세팅)

| 항목 | 값 |
|---|---|
| 운용 금액 | `MAX_CAPITAL_KRW` (시험 운용 10만 원). 계좌에 돈이 더 있어도 이 금액 + 봇이 번 수익까지만 써요. 직접 산 코인은 건드리지 않아요. |
| 감시 | 원화마켓 24시간 거래대금 상위 30개(1시간마다 갱신). 스테이블코인, 유의종목, 상장 7일 미만은 제외 |
| 스캔 | 15분봉이 마감될 때마다 |
| 돌파 | 4시간봉 추세가 하락이 아님 + 1시간봉 20개 고점 돌파 + 최근 1시간 거래량이 평소 2배 이상 → **바로 시장가 진입**. 손절은 돌파선 − 1 ATR, 12시간 안에 +1R을 못 가면 정리 |
| 눌림목 | 4시간봉 상승 추세 + 1시간봉이 EMA20까지 내려옴 + RSI 38~55 → **현재가 − 0.5 ATR에 지정가**, 1시간 안에 체결 안 되면 취소. 손절은 진입가 − 2 ATR, 24시간 시간 손절 |
| 매도 | +1R에서 손절선을 본전으로 → 이후 고점 대비 3 ATR 빠지면 매도. 익절 상한 없음 |
| 비중 | 1회 위험은 확신 high 3%, normal 1.5% (손절 시 잃는 금액). 코인당 최대 45%, 동시 보유 3개 |
| BTC 상태 | 상승 100% · 횡보 70% · 하락 시 **BTC와 상관없이 오르는 코인만**(24시간 BTC 대비 +3%p 이상, 7일도 플러스) 70% 크기 |
| 멈춤 장치 | 3번 연속 손절 시 크기 절반 · 하루 −8%면 그날 진입 중지 · BTC 1시간 −3% 급락 시 대기 매수 취소 + 4시간 진입 중지 · 시작금 대비 −25%면 봇 정지 |

`R`은 진입가에서 손절가까지의 거리예요. 숫자는 전부 `.env`에서 바꿀 수 있어요(`.env.example` 참고).

## 5. 매일 볼 것
- `report.bat`: 최근 7일과 전체 성과를 보여줘요. 승률, 평균 이익/손실(R), 총이익 ÷ 총손실, 최대 낙폭, BTC 보유 대비, 수수료, LLM 비용이 나와요.
- 텔레그램을 설정했다면 매일 23:50에 하루 요약이, 일요일에는 주간 요약이 와요.
- 자가진화 상태는 명령 프롬프트에서 아래 명령으로 볼 수 있어요.

```bash
cd /d "C:\coin ai" && .venv\Scripts\python.exe evolve.py status
```

**증액 기준(1개월 후)**: 총이익 ÷ 총손실이 1.3 이상이고, 최대 낙폭이 15% 이내이고, BTC 보유보다 성과가 나을 때.

## 7. 파일 구성

| 파일 | 역할 |
|---|---|
| `main.py` | 실행 파일(exe 시작점). 대시보드를 띄우고 엔진을 켜고 끔, 중복 실행 방지 |
| `bot.py` | 매매 엔진. 스캔·감시·주문·정비 4개 스레드 |
| `dashboard.py` / `dashboard.html` | 로컬 웹 대시보드(서버 / 화면) |
| `config.py` | 모든 설정값 (`.env`로 덮어쓰기) |
| `upbit.py` | 업비트 API (시세, 계좌, 주문, 호가단위, 중복 주문 방지) |
| `indicators.py` | 지표 계산과 라벨 변환 |
| `strategy.py` | 감시 대상 선정, 셋업 감지, LLM 입력 만들기 |
| `llm.py` | DeepSeek 판단 + Sonnet 5.5 예비 |
| `risk.py` | 운용금, 진입 크기, 손실 한도 |
| `trader.py` | 주문 실행, 체결 확인, 손절선 계산, 재시작 복구 |
| `evolve.py` | 사후 결과 채우기, 자가진화, 섀도 비교 |
| `report.py` | 성과 보고 |
| `notify.py` | 텔레그램 알림 |
| `build_exe.bat`, `.github/workflows/build-exe.yml` | exe 만들기(내 PC에서 / GitHub에서 자동) |
| `coinai.db` | 상태 저장 파일(자동 생성). **지우지 마세요** — 보유 코인과 손절선이 들어 있어요. |
| `coinai.log` | 실행 기록(자동 생성) |

예전 AWS 서버 버전은 `alphabot_server*.tar.gz`에 그대로 보관돼 있어요.
